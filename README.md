# 🛍️ DAM2 - Gestión de Productos y Usuarios (Ionic & Angular)

Aplicación móvil y web multiplataforma desarrollada con **Ionic** y **Angular**, utilizando componentes modernos, **Angular Signals** para la gestión reactiva del estado, y consumo de la API pública de **DummyJSON**. Este proyecto forma parte del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

---

## 🚀 Características Principales

- **Catálogo de Productos:** Visualización de productos en cuadrícula moderna, con precios en euros, valoraciones con estrellas, categorías y barras de indicadores de stock.
- **Directorio de Usuarios:** Secciones de perfiles de usuario estructuradas con avatares, datos de contacto y detalles corporativos.
- **Paginación Avanzada:** Navegación fluida entre páginas mediante parámetros dinámicos (`limit` y `skip`) integrados con la API.
- **Modo Oscuro (Dark Mode):** Cambio de tema dinámico y fluido adaptado tanto para las tarjetas como para los contenedores generales.
- **Gestión Reactiva con Angular Signals:** Uso intensivo de `signal()` y `computed()` para un rendimiento superior y un código más limpio y declarativo.
- **Diseño Moderno (E-commerce / High-End UI):** Estilos limpios, sombras sutiles, efectos *hover* y tarjetas flotantes diseñadas con SCSS avanzado.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

- **Framework:** [Ionic Framework](https://ionicframework.com/) (con componentes standalone)
- **Frontend:** [Angular](https://angular.io/) (TypeScript, Signals)
- **Estilos:** SASS / SCSS
- **Control de Versiones:** Git & GitHub
- **API Externa:** [DummyJSON](https://dummyjson.com/) (Productos y Usuarios)
